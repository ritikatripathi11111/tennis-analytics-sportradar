# Game Analytics: Unlocking Tennis Data with SportRadar API

An interactive tennis analytics platform using SportRadar API, Python, SQL and Streamlit.

## Project modules
- Competitions and categories
- Complexes and venues
- Doubles competitor rankings

## Tech stack
Python, Requests, Pandas, MySQL, SQLAlchemy, Streamlit, Plotly, Pytest.

## Setup
1. Create and activate a virtual environment.
2. Install dependencies: `pip install -r requirements.txt`
3. Copy `.env.example` to `.env` and add your credentials.
4. Configure the database.
5. Run the application: `streamlit run src/dashboard/app.py`

See `docs/` for architecture and database notes.
